# sTudentOS

A web-based Operating system i built in pure HTML, cSS and jAvaScript because i got Bored and wanted to see if i could code a mac desktop in tEh brower.

No frameworks, no react, no npm, nO node server. Just vanilla Code that runs when you open index.html.

---

## Why i mAde this

i wanted a clean Desktop dashboard on my Second monitor while studying for classes. most online Study tools either have to many ads or require paying Monthly subscriptions. so i decided to spend my weekend stayng up untill 3am making my own little web OS with aLl the basic tools i aCtually use every single day.

---

## Featurs

- **Draggable Window Manger**: you can Click and drag the Top title bar of any window to Move it around your screen. clicking on a window brings it to tEh front.
- **Planner & Schedul**: a simple Timetable showing Weekly classes, lecture Hall locations, and a Quick checkbox list for upcoming homework Deadlines.
- **Notes Aplication**: basic Scratchpad for typing lecture Notes. saves directly to browser localstrorage so you Dont loose your text when Refreshing.
- **Caluclator**: Standard grid calculator for Quick math. handles addition, Subtraction, multipication and Division. dont divide by Zero or it shows Error lol.
- **Focus Pomodoro Timmer**: 25 minute Study timer with Reset and pause buttons to stay Focused during cram Sessions.
- **GPA Calculater**: quick tool to calculate Projected cumulative GPA using course Credit weights and Grade points.
- **Termianl**: Simple mock bash CLI interface with basic commands (`help`, `ls`, `whoami`, `date`, `clear`, `echo`).
- **Desktop Sticky Memo**: yellow Memo pad on the Right sidebar for Urgent reminders that Auto-saves as you Type.
- **Wallpaper Switcher**: quick Dropdown in settings to change desktop Background images.

---

## Kown Flaws & Quirks

- if you drag windows to Fast the mouse cursor sometimes slips off the Title bar. just Click it again and it works fine.
- the terminal is nOt a real shell Obviously, its just a bunch of if-else statements Checking string inputs in javascript.
- the top menu bar buttons (File, Edit, Help) just show basic Alert popups because i Havent coded dropdown menus yet.
- Only tested on Google chrome on a desktop Monitor. the layout will definately look wierd on Mobile phones because i didnt write Responsive media queries for tiny Screens.
